きもちチェックについて

「きもちチェック」は、子どもたちが自分のきもちをことばで見つけて、気持ちが楽になるヒントを試してみるきっかけを作るためのサービスです。学童保育や幼稚園・保育園、療育の現場で気軽に使えることを目指して制作に取り組みました。
本サービスは完全非営利であり、課金の必要や広告の表示は一切ありません。

※本サービスは開発途中です。予告なく機能が変更されたりサービスが終了したりする可能性があります。

使い方

子どもの名前を事前に登録しておくと、診断結果の記録・閲覧・データ提供ができます。

1
なまえを登録する
スタート画面の「＋」ボタンから子どもの名前を登録します。登録した名前はこの端末（ブラウザ内）に保存されます。
2
子どもと一緒に質問に答える
名前を選んでスタート！「体調」「気持ち」「元気度メーター」「いたい場所（地図）」「したいこと」の5つの質問に答えます。
3
結果を見て子どもと話し合う
今の子どもの気持ちのまとめが表示されます。「これ、やってみる？」を押すと、気持ちを立て直すヒントになる行動カード（特効薬）が表示されます。カードをタップすると詳しい説明が見られます。子ども達と話し合い、実践してみてください。
4
記録データの確認
スタート画面下部の「📊 気持ち経過観察」から専用画面を開くと、子どもごとの診断履歴を一覧できます。各子どものカード右上にある「❏」ボタンを押すと、その子といいねした行動カードの一覧も確認できます。
5
ゼミにデータを提供する（任意）
気持ち経過観察画面内の「ゼミにデータを提供する」ボタンで、診断データをゼミに送信できます。送信時、子どもの名前は自動的に匿名化（例：しょー → しょ▮）されます。送信いただいたデータは、ゼミでの研究活動に役立てさせていただきます。

内部の仕組み

データの保存について

診断結果・名前・いいねデータはすべてご使用端末のブラウザ（localStorage）に保存されています。プライバシー保護のため、データは外部サーバーに常時送信されることはありません。「ゼミにデータを提供する」ボタンを押したときのみ、Google Apps Script経由でゼミ管理のスプレッドシートにデータが送信されます。

kimochi_names
登録された子どもの名前とアイコン
kimochi_history
診断の履歴（日時、回答内容、場所の座標など）
kimochi_likes
いいねした行動カードの記録

"行動カード"の選ばれかた

約160個の行動カードには、それぞれ5つの質問に対応した「タグ」が設定されています。5つの回答と各行動カードのタグを照合してスコアを計算し、スコアが高いものほど選ばれやすい「重み付きランダム選択」で、画面サイズに合わせて最適な枚数（数枚〜十数枚）を表示します。

しつもんタグの値
からだのちょうしfine / heart / breath / bad / normal
いまのきもちhappy / sad / angry / anxious / normal
いまのげんきさveryhigh / high / mid / low / verylow （メーターの値から換算）
いまどこにいたい？indoor / outdoor / active / calm / alone / friends / teacher / build / desk / book / rest / nature / family / move / music
しましたいことplay / sleep / talk / nothing

スコアは「気持ち」「体調」「したいこと」の一致度に加え、元気度の近さや、今いる場所（地図）のタグとの相性などから複合的に計算されます。選ばれたカードのうち、特におすすめのものには「いいね！」をして記録に残すことができます。

「今のきもち」画面の判定について

診断結果画面のメッセージは、選んだ「気持ち」と「元気度メーター」「体調」の組み合わせから、全25パターンの文章の中から選ばれます。体調がすぐれない場合は、元気度が高くても少し控えめなメッセージになるよう調整しています。

行動カードのジャンル（色）

行動カードは、実はジャンルによって背景の色が分かれています。
