きもちチェックについて

「きもちチェック」は、子どもたちが自分のきもちをことばで見つけて、気持ちが楽になるヒントを試してみるきっかけを作るためのサービスです。学童保育や幼稚園・保育園、療育の現場で気軽に使えることを目指して制作に取り組みました。
本サービスは完全非営利であり、課金の必要や広告の表示は一切ありません。

※本サービスは開発途中です。予告なく機能が変更されたりサービスが終了したりする可能性があります。

使い方

子どもの名前を事前に登録しておくと、診断結果の記録・閲覧・データ提供ができます。

1
なまえを登録する
スタート画面の「＋」ボタンから子どもの名前を登録します。登録した名前はこの端末に保存されます。
2
子どもと一緒に質問に答える
名前を選んでから診断を行うと、結果はこの端末に自動的に記録されます。
3
結果を見て子どもと話し合う
今の子どもの気持ちのまとめが表示されます。次の画面に進むと、今の気持ちを立て直すことに役立つ、具体的な行動カードが10個表示されます。カードをタップして拡大することもできます。子ども達と話し合い、実践してみてください。
記録データの確認
スタート画面下部の「📊 気持ち経過観察」から専用画面を開くと、子どもごとの診断履歴を一覧できます。各子どものカード右上にある「❏」ボタンを押すと、その子といいねした行動カードの一覧も確認できます。
ゼミにデータを提供する（任意）
気持ち経過観察画面内の「ゼミにデータを提供する」ボタンで、診断データをゼミに送信できます。送信時、子どもの名前は匿名化されます。送信いただいたデータは、ゼミでの研究活動に役立てさせていただきます。

内部の仕組み

データの保存について

診断結果・名前・いいねデータはすべてご使用端末のブラウザ（localStorage）に保存されています。診断データは、「ゼミにデータを提供する」ボタンを押したときのみ、Google Apps Script経由でゼミ管理のスプレッドシートにデータが送信されます。

"行動カード"の選ばれかた

約123個の行動カードには、それぞれ5つの質問に対応した「タグ」が設定されています。5つの回答と各行動カードのタグを照合してスコアを計算し、スコアが高いものほど選ばれやすい「重み付きランダム選択」で、PC・タブレットは10個、スマホは8個を表示します。

しつもんタグの値
いまのきもちhappy / sad / angry / anxious
からだのげんきhigh / mid / low / verylow
だれかといたいかsocial / alone / neutral / unsure
からだのかんじfine / heart / breath / bad
いましたいことplay / sleep / talk / nothing

各タグは単一の値・複数の値（配列）・anyのいずれかで設定されます。anyは「どの回答でもマッチするが加点しない」という意味で、候補から除外せずにスコア0として扱われます。

1点以上の特効薬を優先して抽選し、数が不足する場合のみ0点の特効薬から補充します。重みは2のスコア乗（2^score）で計算されるため、高スコアの行動カードほど大幅に選ばれやすくなります。

「今のきもち」画面の判定について

診断結果画面のメッセージは、組合せ爆発を防ぐため、1問目（気持ち）、2問目と4問目（体調）を基に決定しています。現在、よりよい診断結果の算出方法を検討中です。
